# Features

## Identity

* signup/login
* JWT auth
* multi-tenant isolation

## Cluster Management

* add cluster via kubeconfig
* validate connection
* list/remove clusters

## Kubernetes Resources

* pods, deployments, statefulsets, daemonsets
* jobs, cronjobs
* services, ingress
* configmaps, secrets
* pvc, pv
* namespaces

## Operations

* logs (tail)
* events
* exec into pods
* restart workloads
* scale workloads

## Billing

* plan-based feature gating
* usage tracking

## Audit

* track user actions
