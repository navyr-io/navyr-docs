# Flows

## Signup

1. create tenant
2. create admin user
3. assign starter plan

## Login

1. validate credentials
2. return JWT

## Add Cluster

1. validate kubeconfig
2. test connection
3. store cluster

## Inspect Resource

1. select cluster + namespace
2. fetch resource
3. show logs/events

## Exec

1. validate RBAC
2. open session
3. stream output
