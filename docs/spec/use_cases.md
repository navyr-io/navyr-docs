# Use Cases

## UC1 - Investigate failing workload
User selects a degraded workload and inspects logs and events.

## UC2 - Execute command in pod
User opens exec session and runs commands.

## UC3 - Add new cluster
Admin uploads kubeconfig and validates connection.

## UC4 - Multi-tenant access
User only sees resources from their tenant.

## UC5 - Feature restriction
User cannot execute commands if plan does not allow.
